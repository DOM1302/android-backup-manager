# Android Backup Manager

Outil interactif de sauvegarde Android pour Linux,
développé en Python et utilisant Android Debug Bridge (ADB).

## Objectifs

- Détection des smartphones Android via ADB
- Sélection interactive des dossiers à sauvegarder
- Choix du disque ou dossier de destination
- Sauvegardes incrémentales
- Vérification SHA-256
- Rapports de sauvegarde
- Nettoyage facultatif et sécurisé

## Sécurité

Aucune suppression automatique.
Les données doivent être vérifiées avant tout nettoyage.

## Statut

Projet en cours de développement.

## Environnement

- Python 3
- Linux Debian
- Android Debug Bridge (ADB)
